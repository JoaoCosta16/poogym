3. AJUSTES E BUGS RECOMENDADOS NO CÓDIGO
================================================================================

[!] 1. CORREÇÃO DE OPERADOR EM Gestor.java (linha 159):
    - No método adicionarMarcacao(), está escrito:
        if(ocupacaoAtual >+ 1) { return false; }
    - O operador '>+ 1' é interpretado pelo Java como '> (+1)', permitindo 2 inscrições numa Sessão de PT (1-on-1).
    - Para além de parecer um erro de digitação de teclado, deve ser alterado para:
        if (ocupacaoAtual >= 1) { return false; }

[!] 2. MENSAGEM DE ERRO EM Menu.java (linha 302-312):
    - Em registarMarcacao(), se gestor.adicionarMarcacao(marcacao) retornar false (ex.: lotação esgotada), o menu volta sem imprimir mensagem nenhuma ao utilizador.
    - Adicionar bloco else:
        else {
            System.out.println("Erro: Nao foi possivel efetuar a marcacao (lotacao esgotada).");
        }

[!] 3. AVISO NO JAVADOC DE Main.java:
    - O compilador do Javadoc emite 1 warning devido ao construtor por defeito de Main:
        "warning: use of default constructor, which does not provide a comment"
    - Solução: Adicionar um construtor documentado em Main.java para garantir 0 warnings.

[!] 4. MÉTODO toString() EM Instrutor.java:
    - A classe Instrutor continua sem o método toString(). Recomenda-se adicionar para manter a consistência com todas as outras classes do modelo.

[!] 5. FORMATAÇÃO EM Marcacao.toString():
    - Em Marcacao.java, a data está a ser impressa no formato ISO bruto (ex.: 2026-11-02T08:30) e os valores monetários não usam String.format("%.2f", ...).
    - Recomenda-se formatar com DateTimeFormatter ("dd/MM/yyyy HH:mm") e duas casas decimais.
